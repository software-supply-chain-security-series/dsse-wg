# DSSE (Dead Simple Signing Envelope) Working Group

This is the Software Supply Chain Security Series working group that works to push standards for the [DSSE (Dead Simple Signing Envelope) Project](https://dsse.dev).

Note that this working group consists of the same personnel as [the DSSE maintainers](https://github.com/dsse-lf/dsse/blob/master/MAINTAINERS.md).

Please refer all broader discussion about the standards, the standardization process, implementations of the project, adopters, and other concerns to the DSSE project.  You can find more information on the project website:
https://dsse.dev

Organizations who would like to support the Working Group are encouraged to join the [Software Supply Chain Security Series](https://join.sscss.io).
